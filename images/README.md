# Images

Drop image files in this folder, then reference them from index.html as:

    <img src="images/your-file.jpg" alt="Description" width="1200" height="800">

Notes:
- Filenames are CASE-SENSITIVE once live on GitHub Pages (Linux),
  even though Windows ignores case locally. Use lowercase-with-dashes.
- Avoid spaces in filenames; use my-photo.jpg not "my photo.jpg".
- Keep files under ~300KB where possible so pages load fast.
